01 / Bias & variance

Small k memorizes details.

At k = 1, every training point predicts its own label perfectly, including corrupted labels. Small islands in the decision regions reveal sensitivity to individual examples. More neighbors often smooth out this noise; very large neighborhoods can erase useful local structure.

02 / Distance is a choice

Different geometry, different neighbors.

Euclidean distance uses √(Δx² + Δy²). Manhattan uses |Δx| + |Δy|. Chebyshev uses max(|Δx|, |Δy|). Their equal-distance contours are circles, diamonds, and squares in equally scaled feature coordinates. Changing the metric can change who votes.

03 / Preprocessing matters

Units can dominate the answer.

Changing x from 0–1 to 0–100 leaves the information unchanged but changes raw distances. Standardization uses z = (x − μ) / σ for each feature. Its statistics come only from the training set. Scaling should reflect what differences mean in your problem.

Read the experiment conventions

Data and evaluation. Each sample has a balanced training set and 240 independently generated validation points. Label noise flips exactly the selected percentage of training labels (rounded to a whole point); validation labels remain uncorrupted. A new sample changes both sets; model controls keep them fixed.

Training accuracy. This is resubstitution accuracy: each training point is allowed to find itself. It is intentionally optimistic, especially for k = 1. Validation points never vote or contribute to standardization.

Model selection. The curve evaluates every integer k from 1 to min(51, training size). Repeatedly choosing settings using this validation set can overfit it. A real workflow uses cross-validation for tuning and a separate untouched test set for final reporting.

Voting and ties. Uniform voting gives each selected point weight 1. Inverse-distance voting uses 1/d. If any selected distance is zero, only zero-distance matches vote, with equal weights. A tied class vote uses the nearest voting point; equal distances are ordered by point ID. This convention is one of several valid choices.

Plot geometry. Both axes fill the same plot area even when their units differ, so screen distance need not equal feature distance. The dashed contour is computed using the selected metric and preprocessing. Equal-distance points may lie on the outline without being among the k selected voters.

Implementation. Exact brute-force neighbors in two dimensions, seeded synthetic data, and a sampled decision background. KNN stores training examples rather than fitting a parametric boundary. Predictions become costly as data grows, and distance becomes less informative with many irrelevant dimensions.
