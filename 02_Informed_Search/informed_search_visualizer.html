How to read this visualization

Each frame is a decision event, so frame count is not expansion count. Queue rows show current candidates; g is cost already paid, h is an estimate, and f is g + h. RBFS displays backed-up f values. Local-search rows show quality instead of h. Pruned and rejected highlights apply to the current frame. Visit history includes repeated visits and, for annealing, accepted moves. Traces are computed for the shown presets using the notebook’s decision rules, with results checked against its Python functions.
