01 / The idea00–08 min · 8 min

We write the learning procedure.
The data shapes the rule.

A rule-based program follows instructions we specify. A machine learning system uses examples to fit a model, then applies that model to new inputs. Its useful skill is generalization: doing well beyond the examples used to train it.

Examples → a general pattern

After seeing many deliveries, a model may learn how distance and traffic relate to travel time. This is induction. The pattern is an informed guess; another route can still surprise it.

A general rule → a particular conclusion

“Every route over 10 km needs a long-distance fee; this route is 12 km; add the fee.” This is deduction: applying a given rule.

Training does not continue automatically after release. A deployed model usually stays fixed until we deliberately update it.

Artificial intelligence

Making machines perform tasks that require intelligent behavior.

Machine learning

Learning patterns from data.

Neural networks

Connected layers of learned computations.

Deep learning

Neural networks with multiple hidden layers.

Examples + answers

Supervised

Learn from inputs paired with targets. Predict a delivery time or whether a parcel will arrive late.

Examples, no answers

Unsupervised

Look for structure without target labels. Group deliveries with similar characteristics.

A few answers

Semi-supervised

Use a small labeled set together with a larger unlabeled set. Useful when labeling is expensive.

Actions + rewards

Reinforcement

An agent acts, observes the outcome, and learns to improve total reward over time, as in a game.

Two different questions: supervised / unsupervised describes the learning signal. Shallow / deep describes the model. Deep learning can be used with different learning signals.

01Clean

Check missing values, impossible entries, inconsistent units, and duplicate records. Investigate outliers before deleting them.

02Integrate

Join sources carefully. A delivery ID should connect the same delivery across files.

03Encode & construct

Turn categories into numeric inputs. Derive “rush hour” from the departure time: this is feature engineering.

04Scale

Min–max scaling maps a training range to [0, 1]. Standardization subtracts the mean and divides by the standard deviation.

05Aggregate & discretize

Summarize events by day, or replace minutes with time bands. Simpler representations can lose useful detail.

06Reduce

Select useful features, sample rows, or use PCA to represent numeric data in fewer dimensions.

Same deliveries. A different nearest neighbor.

Try both scales

Distance is in km; parcel mass is in grams. Without scaling, grams dominate Euclidean distance. Scaling changes what “near” means.

Training ranges: 0–10 km and 0–5,000 g. The axes change units too, so positions stay fixed. Compare the calculated distances, not line lengths on screen.

Only use information available at prediction time. “Actual arrival time” would reveal the target. Split the data first, then learn imputation values, scaling statistics, and PCA from the training portion.
03 / Keep an honest score20–32 min · 12 min

Practicing and being examined
are different jobs.

A low error on familiar examples is encouraging, but it does not tell us how the model will handle a new delivery. Give each part of the dataset a clear role.

60%TrainingLearn the model's parameters.
20%ValidationChoose models and settings.
20%TestEvaluate the final choice.

These proportions are an example, not a rule. Keep future data after past data for forecasting; keep the same person or delivery out of multiple splits. The split should resemble the situation in which the model will be used.

Five-fold cross-validation

Select a round
used for trainingheld out for validation (gold)

Divide the development data into five parts. For each round, fit a fresh model on four parts and validate on the remaining part. Average the five validation scores to compare settings.

Fit preprocessing inside each fold. The test set stays outside this process. Once settings are chosen, refit on the development data and evaluate on the test set.

A number needs an error measure

Regression: predict a numeric quantity, such as 27.5 minutes. Mean squared error averages squared prediction errors; mean absolute error is in the target's units.

A category needs the right score

Classification: predict a discrete class, such as “late” or “on time.” Accuracy is the fraction correct. If only 5% of deliveries are late, always predicting “on time” gets 95% accuracy and misses every late delivery.

The test set is a final check. Repeatedly changing a model after seeing its test score turns that set into another validation set.
04 / How training works32–44 min · 12 min

Make a prediction. Measure the miss.
Adjust the model.

In linear regression, the prediction is a weighted sum of the inputs plus an intercept. With one feature, that is a straight line. Least squares chooses the line that minimizes squared vertical residuals: actual minus predicted time.

Fit a line to six delivery times

Drag → compare → fit
observationscurrent predictionresiduals

Move either parameter. The line changes; the six observations stay fixed.

Parameters are learned.

The slope and intercept are parameters. Training finds their values. A loss measures the mismatch on an example; the training objective usually aggregates losses over the data.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Gradient descent is one way to optimize an objective: move parameters opposite the gradient. A small learning rate takes short steps; an overly large one can overshoot.

Hyperparameters are chosen.

The learning rate, batch size, tree depth, and neighbor count are settings we choose or tune using validation. They are not learned in the same way as the fitted weights.

parameter ← parameter − learning rate × gradient

Least-squares regression also has a direct solution. KNN does not use this gradient-descent training loop; it keeps the training examples for later comparisons.

Batch, iteration, epoch

A training vocabulary check

A batch is a group of training examples processed together. In a typical mini-batch training loop, one batch produces one parameter update: an iteration.

An epoch is one complete pass through the training set. Here, the last batch is kept even when it is smaller. Three epochs mean three passes, not three updates.

05 / Fit vs. generalize44–56 min · 12 min

Learning the examples
is not the same as learning the pattern.

A model can be too rigid to capture a relationship, or so flexible that it follows accidental details. Complexity describes the patterns a model can represent; parameter count is only one rough indicator.

TOO RIGID

Underfitting & bias

A model with strong restrictions can miss a real relationship. Bias is systematic error in the model's average prediction across training samples.

TOO SENSITIVE

Overfitting & variance

A model may fit the training data closely but perform worse on new examples. Variance is how much its predictions change when the training sample changes.

UNPREDICTABLE DETAIL

Noise

Some variation is not explained by the available inputs: a traffic light, a recording error, or an unmeasured delay. Fitting it more closely may not help.

The practical trade-off: increasing flexibility often lowers bias and raises variance. It is a useful tendency, not a law for every model. Use validation to choose complexity; the lowest training error is not the goal.
06 / Meet the models56–74 min · 18 min

Different ways to turn
examples into a decision.

We have already used linear regression for a numeric target. For classification, imagine predicting whether a delivery will be late. Each method below approaches that question differently.

Logistic regression

Classification

First compute a weighted score, z = w·x + b. The sigmoid turns that score into a probability between 0 and 1. A threshold turns the probability into a class. Despite the name, logistic regression is a classifier.

P(late | x) = σ(z) = 1 / (1 + e⁻ᶻ)

Changing the threshold changes the decision, without changing the fitted probabilities. Training usually minimizes log loss, not squared error.

K-nearest neighbors

Classification / regression

Keep the training examples. For a new point, find its K nearest neighbors. Classification uses a majority vote; regression can average their target values. “Non-parametric” means the model is not restricted to a fixed-size parameterized form.

Small K follows local detail; larger K smooths the vote. Tune K with validation. Distance depends on feature scaling. Circles mark “on time,” squares mark “late,” and the gold diamond is the query.

Support vector machine

Classification / regression variant

A linear SVM seeks a separating boundary with a wide margin. The most influential training points are the support vectors. Soft-margin SVMs allow violations rather than forcing perfect separation.

What the picture says

The solid line makes the decision. Dashed lines mark the margin. Rings identify points touching the margin in this separable example.

A kernel can represent nonlinear boundaries. The regularization setting C controls the penalty for margin violations. Support vector regression uses a related idea for numeric targets.

“Separate the classes” is not enough: the margin helps distinguish possible boundaries. Feature scaling matters here, too.

Naive Bayes

Classification

For a text example, start with a class prior and combine the evidence from words. The “naive” assumption is that features are conditionally independent given the class. Words often violate this assumption, but the classifier can still be useful.

Select observed words:

Toy probabilities: P(spam) = .30; P(free | spam) = .70, P(free | not spam) = .10; P(meeting | spam) = .05, P(meeting | not spam) = .60. Only selected words contribute; absence is ignored.

P(class | words) ∝ P(class) × ∏ P(word | class)

Normalize the two class scores so they sum to 1. The independence assumption concerns words within a class, not words in the whole dataset.

Decision tree

Classification / regression

A tree splits the feature space by asking questions. Training chooses splits that improve class purity or reduce numeric prediction error. A leaf gives a class, a class probability, or a numeric prediction.

A hand-built example to show traversal. A trained tree would learn its questions from data.

A deep tree can memorize small groups of training examples. Depth limits and minimum leaf sizes help control overfitting. Trees usually do not need numeric feature scaling.

Ensembles

Classification / regression

Combine several models instead of relying on one. Bagging trains models on resampled data and combines their predictions. A random forest adds random feature subsets when splitting trees, helping make their errors less alike.

Another approach: boosting

Build models sequentially so later ones address errors left by the current ensemble. AdaBoost increases attention to misclassified examples; gradient boosting fits successive corrections to a loss.

Averaging helps most when models make different errors. Boosting also needs control over complexity.

The figure averages class probabilities, as a forest classifier commonly does. Other ensembles combine votes or weighted scores.

Neural networks & deep learning

Many kinds of tasks

Each layer computes weighted combinations of its inputs and applies an activation function. Hidden layers learn intermediate representations; multiple hidden layers make the network deep. Training adjusts weights through backpropagation and an optimizer.

Why hidden layers help

In images, early layers may detect edges, while later layers combine them into more useful patterns. These features are learned from a training objective rather than individually specified.

The output and loss depend on the task: a numeric value for regression, class probabilities for classification, or other structures for other tasks.

A perceptron is a basic linear classifier. Nonlinear activations between layers let a network represent relationships that a stack of purely linear layers cannot.

07 / Find hidden groups74–85 min · 11 min

What if nobody gave us the labels?

Clustering groups examples by similarity in their features. Classification learns known target classes; clustering discovers groups under a chosen definition of similarity. A cluster is not automatically a meaningful real-world category.

K-means: assign, move, repeat

Step through the algorithm
circles: examplescrosses: centroids

Assign: give each point to its nearest centroid.
Update: move each centroid to the mean of its assigned points.
Repeat until assignments stop changing.

K-means minimizes within-cluster squared Euclidean distances. Choose K beforehand; try multiple initializations. It is sensitive to scale, outliers, and starting centers, and it works best with compact groups. Here, both axes are already on comparable scales.

Hierarchical clustering: keep the merge history

One dataset, three linkages

Agglomerative: start with one cluster per point; repeatedly merge the closest pair of clusters. A dendrogram records the merges. Its height shows merge distance.

Divisive: start with one large cluster and split it. These are bottom-up and top-down approaches, respectively.

K has different jobs. In KNN, K counts labeled neighbors used for a prediction. In K-means, K counts unlabeled groups we ask the algorithm to form.
