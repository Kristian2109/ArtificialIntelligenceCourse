Root = level 1, depth 0. MAX and MIN alternate. Leaf utilities are given from MAX's perspective; seeing a printed utility does not mean the algorithm evaluated it.

? = not entered · … = exploring · × / dashed = pruned. ≥ / ≤ marks a returned bound, rather than an exact value.

What to notice

  • best summarizes children searched so far; it starts at −∞ for MAX and +∞ for MIN.
  • α only increases; β only decreases within a call. Children inherit the parent's current window.
  • A child returns a score; the parent updates best and then its bound.
  • Best-first uses precomputed values only to demonstrate ordering. Real searches use heuristics.

How Minimax plays

For each candidate, search to a win, loss, or draw, alternating X's maximum and O's minimum. Scores appear as candidates are analyzed. Equal scores keep the first move in row-major order. No Alpha-Beta pruning is used in this game.
